# BibCite

Hosted at https://jack-hallybone.github.io/word-bibtex-citation-addin/. Install by sideloading `https://jack-hallybone.github.io/word-bibtex-citation-addin/manifest.xml` in Word via Insert → Add-ins → Upload My Add-in.

To provide a Word add-in for citing references from a local BibTeX library.

This project was written by AI.
